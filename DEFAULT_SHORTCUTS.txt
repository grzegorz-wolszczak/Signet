Column "Where it works":
  Editor       = Code Editor with the focus (the shortcut is handled only there)
  Window       = main window; without an open book the action is blocked
  No book      = the action is available without an open book as well
  XHTML tab    = the action works on the tab of an XHTML file

DEFAULT SHORTCUT CONFLICTS: none (checked by the test KeyboardShortcutManagerTests).
Note: F2 (Rename) is used in two contexts, the Book Browser and the Clip Editor; they never overlap.

WHAT THIS LIST DOES NOT COVER
-----------------------------
- Editor shortcuts of AvaloniaEdit that Signet does not set in the catalog (Ctrl+X/C/V/A, Tab, Home/End).
- Ctrl+click on a class, a link or a color (a mouse shortcut).
- Actions without a default shortcut (among them Next/Previous Bookmark, Navigate Back/Forward, Recent Locations).

Source: src/Signet.App/Actions/AppActionCatalog.cs (the third argument of an entry is its default shortcut).
